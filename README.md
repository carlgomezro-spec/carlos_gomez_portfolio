## Getting Started

Clone the repository:

```bash
git clone https://github.com/carlgomezro-spec/carlos-portfolio.git
cd carlos-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.
